# Amigos del Canal

Landing del Club de Atletismo Pontanés **Amigos del Canal** (Puente Genil) — [amigosdelcanal.com](https://amigosdelcanal.com).

## Desarrollo

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```
